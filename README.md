\# Vulnerability Assessment Tool



\## Overview

This project is a simple Python-based vulnerability assessment tool that scans a system for common security issues, such as unsafe file permissions. It helps identify potential vulnerabilities and generates basic findings to support security analysis.



\## Features

\- Scans for potential security vulnerabilities

\- Identifies world-writable files

\- Basic error handling

\- Generates a vulnerability assessment report



\## Requirements

\- Python 3.x



\## Usage

Run the script using:



```bash

python vulnerability\_assessment.py

```
